## Огляд

cspell:ignore NONWORD яіїєґ MADR-каркас — детермінована власність конвеєра (інверсія форматування: модель повертає лише зміст секцій, увесь markdown-каркас будує цей модуль). Порт розділу «Stage 2: gen-MADR» `normalize-pipeline.mjs`: `validateMadr`/`normalizeSections`/`assembleMadr`/`madrDate`/`slugify`.

## Поведінка

MadrValidation містить підсумок перевірки: ознаку придатності та перелік людських причин відхилення; список причин порожній лише тоді, коли всі умови пройдено.

validate_madr повертає детермінований гейт для згенерованого MADR і може накопичувати кілька незалежних помилок за один виклик; за наявності порушень результат лишається придатним для показу користувачу саме через перелік причин. Це не ізолює зовнішні помилки, що виходять за межі внутрішніх fail-safe гілок.

Sections та normalize_sections задають спільну контрактну форму змісту: порожні значення зберігаються як порожні рядки або порожні списки, а поодинокий текст не блокує приймання; це робить результат стійким до неповного або нерівного виходу моделі.

slugify і madr_date обидві мають fallback-результат для некоректного або бідного входу, тож у користувача завжди є безпечний slug або дата, а assemble_madr збирає канонічний документ із заповнювачами, коли в секціях бракує змісту.

## Публічний API

- MadrValidation — Результат детермінованого гейта якості MADR.
- validate_madr — Порт `validateMadr` — гейт перед прийняттям згенерованого MADR.
- Sections — Нормалізовані секції-зміст від моделі (порт форми `normalizeSections`).
- normalize_sections — Порт `normalizeSections`: сирий JSON моделі → строга форма, толерантна до дрібних відхилень (рядок замість масиву, число/null).
- slugify — Порт `slugify` (ліміт 60 символів, fallback `adr`).
- madr_date — Порт `madrDate`: ISO-дата з `captured`-frontmatter або з timestamp-префікса імені файлу (`YYMMDD-…` → `20YY-MM-DD`), інакше ''.
- assemble_madr — Порт `assembleMadr` — детермінована збірка канонічного MADR 4.0.0. Байтова відповідність JS-версії критична: гейт `validate_madr` і людські diff-и дивляться на той самий текст.
