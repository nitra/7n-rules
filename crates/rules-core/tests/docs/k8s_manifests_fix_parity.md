## Огляд

Cross-language parity фікс-поверхні `k8s/manifests`.  Фікстура знята з ЖИВОГО `fix-manifests.mjs`: кожен трансформер прогнано в Node на тих самих входах, і збережено дослівний вихід (`null` — no-op). Тобто звіряється фактичний канон, а не переказ його логіки.

## Поведінка

Кожен кейс зі `js-k8s-manifests-fix.json` вважається дійсним орієнтиром для звірки: якщо фактичний результат збігається з очікуваним, тест фіксує паритет; якщо ні — показує названу розбіжність між портом і JS-каноном.

Для родини `hasura-configmap-env` приймається єдина різниця у стилі лапок навколо нового рядкового значення; для `svc-clusterip-type` окремо зафіксована допустима розбіжність для провідного `---`. Усі інші відхилення розглядаються як порушення паритету.

Якщо для окремого входу трансформер повертає порожній результат замість тексту, це означає no-op для відповідного кейсу.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Деякі локальні fail-safe гілки повертають порожнє значення (напр. `null`) замість винятку.
