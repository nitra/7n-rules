## Огляд

Cross-language parity фікс-поверхні `k8s/manifests`.  Фікстура знята з ЖИВОГО `fix-manifests.mjs`: кожен трансформер прогнано в Node на тих самих входах, і збережено дослівний вихід (`null` — no-op). Тобто звіряється фактичний канон, а не переказ його логіки.

## Поведінка

Поведінка цієї перевірки прив’язана до зафіксованої JSON-фікстури `js-k8s-manifests-fix.json`: вона очікує, що портований результат для кожного кейсу збігається з живим JS-каноном, а для оголошених винятків — з документованою розбіжністю.

Коли для кейсу JS повертає no-op або помилку, це трактується як відсутність змін для всього документа. Для частини кейсів допускається лише різниця у представленні однаково змістовних значень, якщо вона вже зафіксована як очікувана.

Перевірка не виконує власних записів у файлову систему чи базу даних. Для кейсів, що спираються на зовнішні сніпети `NetworkPolicy`, джерелом є правила пакета, а не окремий користувацький ввід.

Формат результату жорстко стабільний: будь-який незадокументований розбіг між портом і JS-каноном вважається помилкою контракту.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Деякі локальні fail-safe гілки повертають порожнє значення (напр. `null`) замість винятку.
