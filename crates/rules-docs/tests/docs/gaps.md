## Огляд

Дзеркальний набір вердиктів — сценарій-у-сценарій із `tests/gap-engine.test.mjs`, на тій самій фікстурі графа.

## Поведінка

Для базового графа з `base-graph.json` прогалини не виникають, доки немає явного очікування.

Коли очікування присутнє, результат для нього відображає статус узгодження між очікуваним і реалізованим claim: збіг із доказовою прив’язкою дає `satisfied`, відсутність придатного зв’язку — `missing`, пряме заперечення — `diverged`, а слабка впевненість або суперечливі зв’язки — `unresolved`.

Позначене як unresolved очікування лишається unresolved незалежно від інших ознак, а блокувальні перевірки зупиняють формування прогалин і повертають діагностику з причиною для parser або coverage.

Зв’язок, що посилається на відсутній claim, відсутній evidence або недопустимий relation, не ігнорується, а переводить оцінку в блокер.
