## Огляд

Дзеркальний набір зон — сценарій-у-сценарій із `tests/zones.test.mjs`, плюс звірка розбору та запису з живим JS (`fixtures/js-topics.json`).

## Поведінка

Поведінка охоплює парний розбір і захист текстових зон: документ вважається невалідним, якщо маркери не замикаються, id повторюється, формат маркера зламаний або тип зони не підтримується. Для AUTOGEN додатково перевіряється цілісність хеша; будь-яка правка всередині такої зони без оновлення хеша відхиляється.

Під час запису змін оновлюються лише AUTOGEN-зони; захищені ділянки та текст поза ними лишаються недоторканими. Спроба змінити захищену зону або неявний manual-діапазон завершується помилкою, щоб випадкові правки не прослизнули в документ.

Розбір і запис звіряються з живою JS-фікстурою з `js-topics.json`, тож контракт для цього модуля має збігатися з еталонним сценарієм у суміжній реалізації.
