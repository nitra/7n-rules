## Огляд

Дзеркальний набір overlay — сценарій-у-сценарій із `tests/expected-overlay.test.mjs`. Фікстура графа — той самий файл, що читає JS-набір (`tests/fixtures/gaps/base-graph.json`).

## Поведінка

Підтримує лише цілісний вхідний граф і overlay-контент; якщо базовий граф або overlay-контракт зламані, результат блокується замість часткового застосування. Для споживача це означає, що некоректні дані не прослизають як «порожній» або неповний результат.

Очікування без evidence, з невідомим subject поза доменом або з некоректними посиланнями на evidence також блокуються. У разі кількох проблем повертається повний набір діагностик за один прохід, щоб викликач бачив усі порушення одразу.

Успішний результат зберігає вихідний граф незмінним і додає нові сутності в стабільному порядку за id. Для підтвердження поведінки використовує той самий базовий граф із base-graph.json.
