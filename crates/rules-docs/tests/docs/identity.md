## Огляд

Дзеркальний набір узгодження ідентичностей — сценарій-у-сценарій із `tests/identity-migration.test.mjs`, плюс звірка ВСІХ семи результатів із живим JS (`fixtures/js-identity.json`).  Звірка тут важлива через арифметику: схожість тем — це зважена сума трьох перекриттів із порогом 0.75, і зсув на останньому знаку тихо перетворив би «перейменування» на «нова тема» разом із втратою авторського тексту.

## Поведінка

Поведінка цього набору прив’язана до живого JS-еталона `js-identity.json`: він має лишатися синхронним із результатами узгодження, бо саме він фіксує очікувану форму вихідних сценаріїв.

Файл не виконує жодних власних змін стану й не бере на себе зовнішніх побічних ефектів; його контракт — лише перевіряти узгодженість результатів і падати, якщо дані розходяться з еталоном або очікувані сценарії не збігаються.

За невдалих умов можливі лише тестові відмови через невідповідність `MigrationOutcome` або розбіжність із канонічним JSON; локальні fail-safe гілки обмежуються підготовкою даних для перевірки, інші помилки можуть вийти назовні.
