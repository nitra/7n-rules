## Поведінка

Потік починається з обробки `patterns`. Цей елемент інтерпретує перелік `violations`, шукаючи ті, що відповідають `MISSING_GITIGNORE_TARGET_ENTRIES` та мають асоційований файл. Для кожного знайденого випадку виклик `insertMissingTargetEntries` застосовується до вмісту відповідного файлу. Результат взаємодії визначається тим, чи був модифікований вміст файлу, що повертається як частина обробки `patterns`. Якщо модифікації відбулися, генерується повідомлення про виправлення. Якщо ж заголовок відсутній, `insertMissingTargetEntries` додає новий блок із заголовком та відсутніми записами у кінець файлу, забезпечуючи необхідну розділювальну порожню лінію.
