Контракт плагінів `n-rules:plugin` — мінор `3.1.0`: новий host-імпорт `exec-tool`
(`run-tool` плюс `cwd`, накладені змінні середовища й двобічний scratch-обмін
файлами) і слот `scratch-dir@1` на чинному `host-context`. Зміна additive:
плагін, зібраний під v3.0, лінкується й працює без повторної збірки.

Резолв тулів у `manifest.tools` навчився схем (рішення В спеки v3.1):
`path:<name>` резолвиться по PATH замість github-релізу; відсутність схеми —
як було (`pinned:`).

Перший концерн на новій поверхні — `bun/licensee`: детекція ліцензій
npm-залежностей переїхала з JS у wasm-компонент `lang-js/wasm-concerns`
(T0-фікс лишається JS). Спавнений тул виконується з правами хоста, поза
wasm-пісочницею — межа довіри плагіна це його пін, не пісочниця.
