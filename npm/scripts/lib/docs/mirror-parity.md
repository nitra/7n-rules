## Огляд

Parity дзеркала правил: `.cursor/rules/n-<id>.mdc` має дорівнювати канонічному
`main.mdc` правила з inlined-шаблонами — тим самим трансформом, що його
застосовує синк (`readBundledRuleContent` → `inlineTemplateLinks` → mixin-extras).
Дрейф виникає, коли канонічний `.mdc` змінюють, не регенерувавши дзеркало.

Multi-dir: власник правила шукається у `npm/rules/<id>` і `plugins/<p>/rules/<id>`
(перший з `main.mdc`); решта тек `rules/<id>` інших джерел — mixin-extras, їхні
concern-mdc доінлайнюються після концернів власника (як у синку).

Використовується і тестом-гардом (drift === []), і разовою регенерацією.

## Поведінка

listManagedMirrors повертає список керованих дзеркал, що містять ID правила, шлях до дзеркала, канонічний шлях правила та список додаткових джерел, які містять міксини, якщо відповідне правило має канонічне джерело. Якщо жоден власник правила не знайдений, дзеркало не потрапляє до списку.

expectedMirrorContent генерує очікуваний текст для дзеркала шляхом обробки канонічного файлу правила та додавання вмісту всіх додаткових джерел міксинів. Це формування включає застосування шаблонів і збір усього вмісту Concern-mdc.

findMirrorDrift повертає відсортований список ID дзеркал, чий фактичний вміст не відповідає очікуваному вмісту, згенерованому на основі канонічного джерела та додаткових міксинів.

## Публічний API

- listManagedMirrors — Керовані дзеркала `.cursor/rules/n-<id>.mdc` з канонічним джерелом у ядрі або плагіні.
Дзеркала без канону (зовнішні) пропускаються.
- expectedMirrorContent — Очікуваний вміст дзеркала = канон з inlined-шаблонами + concern-mdc mixin-джерел
(той самий трансформ, що у синку).
- findMirrorDrift — Id дзеркал, що розійшлися з каноном (actual ≠ expected).

## Сценарії використання

- `npm/scripts/lib/tests/mirror-parity.test.mjs` (findMirrorDrift; live parity (цей репо)) — mirror == канон (без шаблонів) → без дрейфу; mirror ≠ канон → дрейф [x]; дзеркало без канону пропускається (не дрейф); усі задекларовані плагіни встановлені (інакше drift-гард порівнює не з тим каноном); .cursor/rules/n-*.mdc == inlined-канон (нема дрейфу)
