## Огляд

`runOneShot` виконує одноразовий запит до вибраної моделі чи tier без agent-циклу і використовується як точка входу для сценаріїв, де потрібна одна відповідь без подальшої взаємодії. У файлі є локальні fail-safe гілки для окремих збоїв.

## Поведінка

1. Приймає набір повідомлень, зводить їх в один запит і рахує його відбиток для подальшого трасування.
2. Визначає модель виконання: або за явним spec, або за tier; якщо вибір не задано, повертає контрольовану помилку без запуску запиту.
3. Перевіряє, чи існує запитана модель; якщо ні — завершує виклик керованою помилкою.
4. Ініціює одноразову сесію без інструментів, щоб отримати plain completion без agent-циклу.
5. Відправляє запит із лімітом часу; якщо під час виконання виникає memory-guard відмова локального model-сервера, пробиває її назовні як fail-fast сценарій.
6. Акумулює текст відповіді та службову інформацію про завершення; якщо відповідь обрізана стелею, це фіксується у stop reason для рішення колером.
7. Після завершення повертає очищений текст відповіді, usage, помилку за потреби, фактичну модель, stop reason і caller.
8. Додатково пише trace і capture для спостережуваності, але не гарантує обробку всіх зовнішніх помилок.
