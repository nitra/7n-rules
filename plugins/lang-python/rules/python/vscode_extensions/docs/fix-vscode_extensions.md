## Огляд

Містить re-export `patterns` з іншого модуля, щоб інший код міг використовувати той самий набір правил без дублювання джерела.

## Поведінка

1. Надає доступ до `patterns` з іншого модуля.
2. Дає змогу спиратися на спільне джерело правил там, де використовується цей експорт.
3. Не додає власної логіки обробки чи зміни даних.
4. Не виконує власних записів у файлову систему чи базу даних.
5. Не аналізує імпортовані модулі та не перевіряє їхній внутрішній вміст.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
