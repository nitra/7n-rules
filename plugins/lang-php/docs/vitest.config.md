## Огляд

Vitest-конфіг плагіна lang-php: env-канон ядра + include лише тестів плагіна.

## Поведінка

Конфігурація забезпечує виконання тестів, які стосуються лише логіки самого плагіна `lang-php`, ігноруючи залежності з каталогу `node_modules`. Тестування відбувається у середовищі `node` з встановленим часовим лімітом виконання в 20000 мілісекунд.

Виконання тестів завжди відбувається у режимі форкових процесів (`forks`). При цьому встановлюється специфічний для ядра процес трасування (`GIT_TRACE2_EVENT=0`) та вказується шлях до логування трасування LLM у тимчасову директорію.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
