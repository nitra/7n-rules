## Огляд

Vitest-конфіг плагіна lang-php: env-канон ядра + include лише тестів плагіна.

## Поведінка

У тестовому середовищі плагіна фіксується ізоляційний контракт: виконання відбувається в Node-середовищі, з вимкненим Git trace2 event і з окремим шляхом для LLM trace у тимчасовій теці.

Тести з `node_modules` свідомо не потрапляють у запуск, навіть якщо відповідають шаблонам тестових файлів плагіна.

Паралельність стабілізована через fork-процеси, щоб стан одного тестового виконання не забруднював інше в межах спільного процесу. Максимальна тривалість окремого тесту обмежена 20 секундами.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
