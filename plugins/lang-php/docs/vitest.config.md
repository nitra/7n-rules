## Огляд

Vitest-конфіг плагіна lang-php: env-канон ядра + include лише тестів плагіна.

## Поведінка

Виконання тестів відбувається лише для файлів, що належать до правил плагіну `lang-php`, а також для тестів у секціях `slots` та `taze`. Всі залежності з каталогу `node_modules` ігноруються під час виконання тестування.

При виконанні тестів встановлюється специфічний середовище, що включає встановлення змінних `GIT_TRACE2_EVENT` на `0` та шляху для трасування LLM у тимчасовому каталозі.

У разі перевищення часу виконання тесту, спрацьовує тайм-аут у 20 секунд. Тестування виконується у режимі `forks`.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
