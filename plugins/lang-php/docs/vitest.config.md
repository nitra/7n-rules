## Огляд

Vitest-конфіг плагіна lang-php: env-канон ядра + include лише тестів плагіна.

## Поведінка

Плагіновий Vitest-запуск обмежує видимість тестів межами `rules`, `slots` і `coverage-provider`; усе поза цими зонами не входить у його контракт.

Середовищні змінні для trace-поведінки зафіксовані на рівні контуру запуску, тож результати тестів не залежать від локальних trace-налаштувань процеса.

Паралельне виконання через fork-пул означає, що окремі тести мають сприймати ізоляцію процесів як частину стабільної поведінки.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
