## Огляд

Vitest-конфіг плагіна lang-js: env-канон ядра + include лише тестів плагіна.

## Поведінка

Виконання тестів відбувається лише для файлів, явно вказаних у секції `include`, зокрема, для тестів компонентів плагіна, ядра та знань.
Ігнорується будь-який вміст у каталозі `node_modules`.
Тестування налаштовано на роботу в середовищі `node`.
Запуск процесу може бути обмежений часовим вичерпанням, встановленим на 20000 мілісекунд.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
