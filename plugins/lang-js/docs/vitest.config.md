## Огляд

Vitest-конфіг плагіна lang-js: env-канон ядра + include лише тестів плагіна.

## Поведінка

Тестування конфігурується лише для тестів самого плагіна, виключаючи тестові файли з каталогу `node_modules`. Середовище тестування встановлене як `node`. Встановлено обмеження на час тестування у 20 секунд та використовується пулінг через `forks`. Змінні середовища встановлені для імітації ядра, включаючи фіксацію трасування Git та шлях для трасування LLM.

## Гарантії поведінки

- Власних операцій запису (ФС/БД) у файлі немає; виклики імпортованих модулів можуть писати.
- Свідомо пропускає шляхи: `node_modules`.
