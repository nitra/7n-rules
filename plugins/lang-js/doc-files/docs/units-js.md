## Огляд

Розбирає JavaScript/TypeScript-файл у список верхньорівневих юнітів: функцій, класів і `const`-ініціалізацій з function або arrow function.

Відокремлює внутрішні та експортовані декларації, зберігає межі коду, тіло та супровідну документацію для кожного юніта.

Якщо файл не вдається розібрати, повертає `null`.

## Поведінка

1. Розбирає вхідний JavaScript/TypeScript-код у структуру програми; якщо файл не вдається розібрати, повертає `null`.
2. Проходить лише верхньорівневі декларації та виділяє окремі юніти з функцій, класів і const-ініціалізацій, де значенням є function або arrow function.
3. Для кожного юніта фіксує ім’я, вид, ознаку експорту, межі фрагмента коду, тіло юніта, список викликів і текст документації, що стоїть безпосередньо перед декларацією.
4. Якщо декларація огорнута export-обгорткою, юніт позначається як експортований; інакше — як внутрішній.
5. Під час збирання викликів враховує лише прямі звернення до іменованих функцій і методів із простим доступом до властивості, щоб сформувати базу для call-graph.
6. Після збирання всіх юнітів залишає у викликах тільки посилання на інші внутрішні юніти цього ж файлу та прибирає самовиклики.
7. Повертає список знайдених юнітів або `null`, якщо файл не піддається парсингу.
