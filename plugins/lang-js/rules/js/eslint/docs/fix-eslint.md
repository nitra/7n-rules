## Огляд

patterns керує застосуванням безпечних правок і має локальні fail-safe гілки для окремих випадків. Якщо дія не може бути виконана безпечно, частина таких гілок повертає порожнє значення замість винятку; інші помилки можуть поширюватися назовні.

## Поведінка

1. `patterns` описує два кроки автоматичного усунення порушень для JavaScript-файлів: спершу детермінований autofix через lint-інструменти, потім точкові текстові заміни для окремих механічних випадків.
2. Для `js-eslint-autofix` спочатку відбираються лише JavaScript-файли з переліку порушень, після чого запускається autofix. Якщо змін немає, результат порожній; якщо файли змінено, вони повертаються як touched files і фіксуються як записані.
3. `js-eslint-autofix` працює тільки для файлів, які реально можна виправити автоматично; якщо інструмент недоступний або файл не читається, це не зупиняє весь прогін, а інші помилки можуть піднятися назовні.
4. Для `js-eslint-mechanical-text-fix` система шукає лише ті порушення, для яких є безпечна текстова заміна на конкретному рядку. Якщо рядок уже змінився або очікуваний шаблон не збігається, зміна пропускається без припущень.
5. Якщо механічні заміни дали результат, відповідні файли повертаються як touched files і записуються на диск; якщо ні — результат порожній.
6. Усі інші випадки, які не входять у ці два сценарії, `patterns` не обробляє.

## Гарантії поведінки

- Містить локальні fail-safe гілки; інші помилки можуть поширюватися назовні.
- Деякі локальні fail-safe гілки повертають порожнє значення (напр. `null`) замість винятку.
